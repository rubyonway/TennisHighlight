# 网球视频复盘 Skill

把网球原片或已有分析结果整理为完整回合集锦、可追溯统计、落点示意、动作建议和一个可播放视频的 HTML 报告。

## 能做什么

- **剪集锦**：保留回合到死球，按球路调整构图，保留现场声音，支持轨迹与章节。
- **做统计**：正手／反手／类型不明分别统计，保留结果未知；每项比例展示分母与覆盖范围。
- **看落点**：区分可见弹地、轨迹估计、带先验估计和未知，支持点击回看。
- **给建议**：动作现象绑定原片时间与图像，提供可执行练法。
- **统一报告**：同页播放集锦和原片浏览版，筛选逐球明细，按时间定位。
- **接续工作**：复用已保存文件，从验证过的进度继续，避免重复剪辑和分析。

这是指导 Codex 执行工作的 skill，包含统计与预览辅助脚本，**不是开箱即用的自动网球识别模型**。识别质量取决于机位、清晰度、遮挡与复核情况。

## 安装与使用

将整个 `tennis-video-review` 文件夹放入 Codex 的 skills 目录。新会话中可明确调用：

```text
用 $tennis-video-review 剪这三段网球视频，以白衣球员为主，保留完整回合，并统计全片正反手表现。
```

已有结果时：

```text
用 $tennis-video-review 把这个目录里的集锦、JSON 和动作建议整合成一个 H5，不重新识别视频。
```

技能入口与完整执行说明见 [SKILL.md](SKILL.md)。使用者应提供视频／项目路径、目标球员与需求范围。中断恢复时优先读取项目说明和已有交付。

## 辅助脚本

要求 Python 3.9 或以上，脚本只使用标准库。视频处理按任务需要使用本地 FFmpeg／FFprobe，未绑定专有模型、公司内网或云服务。

```bash
# 对已有逐球标注重新汇总，保留未知结果，不覆盖已有输出文件
python3 scripts/summarize_events.py /path/to/events.json --output /path/to/summary.json

# 本地播放预览，支持拖动视频进度；仅监听本机
python3 scripts/serve_report.py /path/to/report-folder --port 8921

# 使用合成数据验证辅助脚本
python3 scripts/check_helpers.py
```

数据示例与结果口径见 [数据与报告约定](references/data-and-report.md)，视频处理细节见 [视频分析与剪辑](references/video-analysis.md)。

## 能力边界

高光样本不代表全场。回合延续有效率不等于界内率。单机位估计不能冒充鹰眼判罚、雷达离拍球速或三维挥拍峰值。用户提供的场内观察作为先验时必须标明，不能再拿拟合结果证明该观察。

本仓库只包含可复用说明、脚本和合成校验数据，不包含私人训练视频、逐球记录或账号信息。生成本地报告不会自动发布到互联网。
